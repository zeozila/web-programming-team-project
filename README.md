# SeoulBaatar

Team 6 – Web Programming final project

A travel guide website for Korea and Mongolia. You choose where you are going (Korea or Mongolia) and the site shows places, trip plans, phrases, money and weather for that country.

**Live site:** https://zeozila.github.io/web-programming-team-project/

## Pages

- **Home** – slideshow, Seoul/UB clocks, exchange rate, top places, trips, food
- **Explore** – 26 places on a map with filters and search
- **Trips** – 9 trip plans with day-by-day itinerary, route map, cost and reviews
- **Phrasebook** – Korean and Mongolian phrases with audio and flashcards
- **Planner** – currency converter, weather, budget, packing list, saved places
- **Quiz** – culture quiz about Korea and Mongolia
- **About** – team and photo credits

## Built with

HTML, CSS, JavaScript, Leaflet (map), Open-Meteo API (weather), ExchangeRate-API (currency), localStorage, GitHub Pages.

Photos are from Wikimedia Commons (credits on the About page).
